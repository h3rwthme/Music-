Cara install

Pertama kali pasang dari luar Play Store? Ikuti 3 langkah ini.

1

Unduh & buka

Buka music-player.apk dari notifikasi atau folder Download.

2

Izinkan pemasangan

Nyalakan “Install aplikasi tidak dikenal” untuk browser/File Manager.

3

Play Protect

Ketuk Selengkapnya → Tetap instal.

Masih gagal?

HP SamsungMatikan sementara Pemblokir Otomatis di Pengaturan → Keamanan dan privasi.
“Aplikasi tidak terpasang”Butuh Android 7.0+ 64-bit dan ruang penyimpanan cukup.
UpdateTidak perlu uninstall — install menimpa versi lama.
