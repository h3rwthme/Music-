Cara Install APK

Karena diunduh langsung dari GitHub (di luar Play Store), ikuti 3 langkah singkat ini saat pertama kali memasang aplikasi.

Panduan Visual Pemasangan

3 Langkah
1

Unduh & Buka APK

Klik tombol Unduh, lalu buka file music-player.apk dari notifikasi browser atau folder Download.

2

Izinkan Sumber Tidak Dikenal

Kalau diminta izin “Install aplikasi tidak dikenal”, nyalakan toggle untuk browser / File Manager yang dipakai, lalu kembali.

3

Lewati Google Play Protect

Jika muncul peringatan Play Protect, jangan klik OK. Klik Selengkapnya (More details) lalu pilih Tetap instal (Install anyway).

Kalau Masih Gagal Install

Samsung & Syarat HP
HP Samsung (One UI 6+) Matikan sementara Pemblokir Otomatis (Auto Blocker) di Pengaturan → Keamanan dan privasi → Pemblokir Otomatis, lalu install lagi.
Muncul “Aplikasi tidak terpasang” Pastikan HP memakai Android 7.0+ (64-bit / arm64-v8a) dan ruang penyimpanan cukup. HP 32-bit lama memang belum didukung.
Update dari Versi Lama Tidak perlu uninstall. Cukup install menimpa versi sebelumnya — playlist, lagu disukai, dan cache offline tetap aman.
Siap pasang?

Masih ragu soal peringatan Play Protect? Cek hasil scan 0/67 VirusTotal dulu.
